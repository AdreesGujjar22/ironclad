# Ironclad Commercial Floors

Commercial flooring contractor website for Ironclad Commercial Floors, serving Vancouver and the Lower Mainland.

## Local development

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Project structure

- `src/routes` contains the TanStack Start route tree.
- `src/pages` contains page-level content and layouts.
- `src/data` contains service, location, and blog content.
- `public` contains static assets and SEO files.
